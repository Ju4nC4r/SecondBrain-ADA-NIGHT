# Fuentes originales

Conserva las fuentes sin modificarlas. Añade versiones nuevas en archivos separados cuando sea necesario.

- `articles/`: Artículos y noticias.
- `papers/`: Trabajos académicos y documentos técnicos.
- `reports/`: Informes originales.
- `data/`: Archivos de datos.
- `transcripts/`: Transcripciones.
- `notes/`: Notas originales aportadas por el usuario.
- `repos/`: Repositorios o documentación de proyectos.
- `assets/`: Imágenes y otros adjuntos de las fuentes.

Para una fuente web, conserva su URL, autor y fechas de publicación y captura en una nota asociada. Las páginas derivadas se escriben en `wiki/`.
