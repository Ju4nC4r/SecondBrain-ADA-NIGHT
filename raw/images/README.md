# Imágenes originales para la wiki

Carpeta creada por indicación del usuario el 5 de octubre de 2026 para conservar las imágenes descargadas o necesarias para la wiki.

Usar nombres descriptivos en minúsculas y con guiones; añadir fecha cuando identifique la captura o publicación. Registrar en la ficha de fuente o en una nota de procedencia la URL o archivo de origen, autor cuando conste, fecha de publicación si se conoce, fecha de captura y relación con las páginas que utilizan la imagen.

Conservar el original sin modificar. Si hace falta una versión nueva o derivada, guardar otro archivo y registrar su relación con el anterior. Las páginas de la wiki enlazarán las imágenes con rutas Markdown relativas a esta carpeta. Los demás adjuntos continúan en `raw/assets/`.

No se han descargado imágenes adicionales al crear esta carpeta.

Posteriormente, el mismo día, se incorporaron los [recursos visuales del índice](../../wiki/sources/2026-10-05-recursos-visuales-indice.md), con [metadatos de origen y huellas](2026-10-05-imagenes-indice-metadatos.json). La frase anterior describe el momento inicial de creación de la carpeta.

Las [copias PNG para el índice](2026-10-05-logotipos-indice-png-metadatos.json) son versiones derivadas de presentación. Sus metadatos las relacionan con los SVG originales y documentan la rasterización, el fondo y las dimensiones; no sustituyen los originales.
