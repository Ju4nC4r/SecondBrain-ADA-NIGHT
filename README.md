# SecondBrain-CryptoADA

Base de conocimiento personal sobre Cardano (ADA) y Midnight (NIGHT), organizada según la propuesta LLM Wiki de Andrej Karpathy.

## Punto de entrada

- [Índice de la wiki](wiki/index.md): catálogo de páginas y categorías.
- [Visión general](wiki/overview.md): alcance, estado y preguntas abiertas.
- [Registro de actividad](wiki/log.md): historial cronológico.
- [Esquema de mantenimiento](AGENTS.md): convenciones y flujos de trabajo.
- [Guía original](llm-wiki.md) y [traducción al español](llm-wiki-es.md).

## Organización

`raw/` conserva las fuentes originales. `wiki/` contiene las páginas elaboradas a partir de ellas. `templates/` ofrece modelos para nuevas páginas. El esquema está en `AGENTS.md`.

La estructura está preparada; aún no se han incorporado noticias ni informes sobre ADA o NIGHT. El documento de Karpathy es la primera fuente de referencia.

## Uso

1. Guarda una fuente en la categoría adecuada de `raw/`, con un nombre descriptivo. Para fuentes web, conserva la URL, el autor y las fechas de publicación y captura junto a la copia.
2. Solicita su incorporación. El proceso produce un resumen con citas, actualiza páginas relacionadas y registra los cambios.
3. Consulta la wiki a partir de su índice. Conserva los análisis útiles como páginas enlazadas.
4. Revisa periódicamente las contradicciones, afirmaciones desactualizadas y enlaces rotos.

Esta carpeta puede abrirse como bóveda de Obsidian. Para los adjuntos de las fuentes, la guía propone `raw/assets/`. Obsidian y sus complementos son opcionales y no se han instalado ni configurado.

El repositorio Git local permite llevar un historial cuando se registren cambios. No tiene ningún remoto configurado. El buscador qmd y las herramientas de presentaciones son opcionales; el índice es el punto de partida.
